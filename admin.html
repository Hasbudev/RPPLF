Comment créer un token ?

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access : uniquement ce dépôt. Permissions → Repository → Contents : Read and write. Le token reste dans ton navigateur et n'est envoyé qu'à api.github.com.
